# scripts/

Scripts utilitarios (bash, python, etc.) para operacoes no segundo cerebro.

## Sugestoes

- `context-pack.sh` — gera bundle markdown para colar em AIs sem acesso a arquivos
- `lint.sh` — verifica saude da wiki (orfaos, claims sem fonte, desatualizados)

## Quando criar script vs. pedir pra AI

- Se voce vai rodar a mesma operacao 10+ vezes -> script
- Se e one-off -> so pede pra AI via prompt

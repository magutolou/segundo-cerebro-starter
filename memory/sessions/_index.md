# memory/sessions/

Log diario — uma pagina por dia: `YYYY-MM-DD.md`.

Multiplas sessoes no mesmo dia viram subsecoes `## Sessao HH:MM`.

## Template

```markdown
# Sessao — YYYY-MM-DD

## O que foi feito
- ...

## Decisoes
- (omitir se nada)

## Atualizacoes na wiki
- (omitir se nada)

## Em aberto
- ...
```

## Regra

**Nunca sobrescrever sessao existente.** Sempre append.
